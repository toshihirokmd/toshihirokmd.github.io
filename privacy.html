Privacy policy

最終更新日：2026年11月26日 / Last updated: 26 November 2026

1. 誰のデータを扱うか

このツールが扱うのは、所有者本人の Google アカウントに紐づくデータだけです。ほかの人のアカウントやデータは使いません。

This tool uses only the owner’s own Google account data. It does not access anyone else’s accounts or data.

2. 取得するデータの種類

Google Health API を通じて、次の種類のデータを読み取ります（読み取りのみ）。

  • 活動とフィットネス（歩数、運動、活動量など）
  • 健康指標（心拍数、心拍変動、血中酸素、呼吸数、皮膚温など）
  • 睡眠
  • プロフィール（本人確認に必要な範囲）

It reads, and does not write, the following types of data via the Google Health API: activity and fitness (such as steps, exercise, and activity minutes); health metrics (such as heart rate, heart-rate variability, blood oxygen, respiratory rate, and skin temperature); sleep; and profile information needed to confirm the account.

3. 保存場所と共有

取得したデータは、所有者自身の機器にだけ保存します。第三者と共有せず、第三者へ送信せず、広告にも使いません。公開したり、ほかのサービスへアップロードしたりしません。

Data is stored only on the owner’s own devices. It is not shared, sold, or sent to third parties, is not used for advertising, and is not published or uploaded to other services.

4. Google の Limited Use への適合

このツールは、Google API Services User Data Policy の Limited Use 要件に従います。取得したデータは、所有者が自分のデータを手元に保存し、確認するという、本人が求めた機能を提供するためにだけ使います。ほかの人向けの広告、販売、モデルの学習などには使いません。

The tool complies with the Limited Use requirements of the Google API Services User Data Policy. Data is used only to provide the owner-requested function of storing and reviewing the owner’s own data on the owner’s devices. It is not used for advertising, sale, or training models for others.

5. アクセスの取り消し

このツールへのアクセスは、次のページからいつでも取り消せます。

https://myaccount.google.com/permissions

You can revoke the tool’s access at any time on that page.
