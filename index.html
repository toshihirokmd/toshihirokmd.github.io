fitbit-air-personal

所有者本人だけが使う、個人用のツールです。

A personal-use-only tool for its owner.

このツールについて

fitbit-air-personal は、所有者が自分の Fitbit データを Google Health API で読み取り、所有者自身の機器に保存するためのツールです。第三者への提供、共有、広告利用はありません。

It reads the owner’s own Fitbit data through the Google Health API and stores that data only on the owner’s own devices. The data is not shared, transferred to third parties, or used for advertising.

対象

対象は、所有者本人の Google アカウントに紐づくデータだけです。ほかの人のデータは扱いません。

Only data from the owner’s own Google account is used. No one else’s data is processed.
